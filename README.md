# did:btcr2 Test Suite

This repository contains files that can be used to test implementations of the **did:btcr2** DID Method on multiple Bitcoin test networks.
All test vectors were generated by the [did-btcr2-js](https://github.com/dcdpr/did-btcr2-js) reference implementation.
* [regtest](./regtest) 
* [signet](./signet)
* [mutinynet](./mutinynet)
