# did:btcr2 Mutinynet Test Vectors

Live `did:btcr2` examples anchored on **Mutinynet** (a custom signet), mirroring the 12 reference examples from danubetech's [uni-resolver-driver-did-btcr2](https://github.com/danubetech/uni-resolver-driver-did-btcr2). Generated by the `@did-btcr2/method` scenario orchestrator.

- **On-chain:** each update's beacon signal is anchored in an `OP_RETURN` on Mutinynet (https://mutinynet.com).
- **CAS:** genesis documents, signed updates, and CAS Announcement Maps marked *(from CAS)* are published to **IPFS** (CIDv1, raw, sha2-256) and retrievable from any public gateway.
- **Sidecar:** data marked *(from Sidecar)* — including all SMT proofs — is supplied in the resolution options.

Each example lives under `{type}/{hash}/` with `create/`, `update/`, and `resolve/` input + output files. Each example below gives the **DID** to resolve and, when the example carries sidecar data, the **resolution options** to pass alongside it.
